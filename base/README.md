# Base de referência

O arquivo natalreport.sty é a revisão 0.4.1 do pacote-base recebido. A compilação histórica com o main.tex original foi verificada em MiKTeX, usando LuaLaTeX. O main.tex original contém dados de nascimento identificáveis e fica no arquivo local da entrega.

O demonstrativo compilável está em demonstrativo/. A integração com a base ainda é trabalho do motor. A proveniência e a licença do pacote e da fonte Symbola requerem verificação para uso comercial.
